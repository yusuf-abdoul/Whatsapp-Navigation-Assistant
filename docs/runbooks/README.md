# Runbooks

Operational procedures for on-call and incident response. Populate these as real incidents happen — don't invent runbooks for hypothetical failures.

Planned runbooks:

- `locationiq-outage.md` — what to do when geocoding/routing fails broadly
- `meta-webhook-down.md` — inbound message failures
- `redis-connection-lost.md` — session store unavailable
- `rate-limit-abuse.md` — how to investigate and block abusive numbers
- `render-deploy-rollback.md` — rollback procedure
