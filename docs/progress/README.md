# Progress Reports

One short report per completed phase. Read these to catch up on what's been built, why, and what's left — without grepping the diff.

Format for each report:
- **What we built** — plain-English summary
- **Why this came when it did** — the reason for the order
- **Files added / changed** — pointers to the work
- **What's left** — the next visible step

Reports are written when a phase is done, not while it's in progress.
